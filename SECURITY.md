# Security policy

Please do not report vulnerabilities by publishing exploit details or real credentials in a public issue. For now, use a private report to the repository maintainer if the hosting platform supports it. If a credential has been exposed, revoke or rotate it immediately; CloakSift cannot undo an exposure.

CloakSift is an early-stage heuristic scanner, not a substitute for secret management, code review, provider-side controls, or a dedicated security program.
